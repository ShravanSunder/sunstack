# 2026-10-15 How and why practices

`sunstack-dev` 2.78.0 → 2.79.0.

- `practices-how` (new, model- and user-invocable): explains how existing code works by tracing a real entry through owners, state changes and effects back to the result or error. It resolves each edge's semantics from the actual dispatcher, queue or await site, checks which implementation is wired in, and keeps source-established, capture-confirmed and inferred edges apart. References: `behavior-reconstruction.md` and `dynamic-path-evidence.md`.
- `practices-why` (new, model- and user-invocable): reconstructs recorded rationale. It walks back past the last touch to the commit that introduced a behavior, loads `practices-research` for evidence, and counts a reason as adopted only when the opened decision context supports it; a link alone is a pointer. Answers keep facts, supported interpretations and unknowns apart, and explain without approving changes. References: `rationale-reconstruction.md` and `rationale-confidence.md`.
