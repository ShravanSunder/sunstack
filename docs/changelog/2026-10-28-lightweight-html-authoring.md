# 2026-10-28 Lightweight HTML authoring

`sunstack-dev` 2.100.2 reduces routine `presentation-html` authoring to one static lint pass on changed HTML. It removes required browsers, screenshots, phone/theme matrices, shared-control regression journeys and duplicate regenerate-and-compare passes. Explicit visual verification requests and concrete rendering defects keep their scoped browser path. Shared-reference and fetched-guide proof procedures no longer expand routine authoring into a browser task.

The matching Demistify guide owns its CLI; the CDN tarball can run through pnpm dlx or npx without a repository checkout. Older bindings retain their documented tool route. Content/source preservation, component selection and API binding remain part of authoring.

Validation: focused source/diff and six-manifest metadata checks. Browser verification is intentionally unnecessary for these instruction changes. Client caches were not refreshed; this is a source change until merged and installed.
