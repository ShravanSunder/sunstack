# 2026-11-06 Show me your work: every agent logs its own work, and the owner's page

`sunstack-dev` 2.106.0 → 2.107.0 (main took 2.105.0 and 2.106.0 for #199 while this was open). Basis: user-directed intent from the owner's design cycle (design set accepted to implement); behavior not yet evaluated.

- **Every agent logs its own work.** `practices-show-me-your-work`: each agent writes its own decisions, assumptions, shortcuts and checks into the work trail as they happen, with a two-step write (mint a request id and a row id, then write; an unknown outcome is retried with the same ids and never duplicates; a refused write is checked against the trail before anything is written again). New row kinds `shortcut` (replacing `design-change` for new rows), `missed` and `audit`; a `stream:` workstream tag; `Ran by:` on a check someone else ran. A new audit step: each agent compares its stretch with its own session before handing back and at each checkpoint.
- **The owner's page.** `references/show-me.md` replaces `references/live-page.md` and teaches the page the owner approved: four sections (For you to decide; What's done / what's next; What changed and why, with two decision columns; What was verified, with what was missed and audit status), each Story a headline with Happened, For you and Next and its cited rows folded, in plain words, and a Map tree whose rows open the Stories. A Story's `Covers:` line names every row it cites, past Router's 16-link limit. The Lead builds it with Demistify's parts; no script.
- **Commissions carry the log.** `practices-manage-agents`: every packet carries `workLog` (`schemas/assignment-fields.ts`) with the filled write command; the commissioner checks the helper's own rows at handback and logs each missing one as missed.
- **Every role logs.** `role-reviewer`, `role-verifier`, `role-researcher`, `role-implementer`, `role-advisor` and `role-operator` log their own rows whenever the packet names a work trail, whatever their posting authority. `implement-plan` logs a design break or plan defect as a shortcut, and `orchestrator-implementation-goal`'s routing reference points its page rebuild at the right step.
- The plugin manifests (Codex, Claude Code, Cursor) and the Claude and Cursor marketplace versions move to 2.107.0; the Codex marketplace entry is unchanged.
- **Validation:** `pnpm --dir tests/skills test` passes, including a contract test that rejects a packet without `workLog`; `rules --check` and `claude plugin validate .` pass; the keyed rules on the nine changed skills report 0 errors and 6 nudges, each read and accounted for; a retry probe on a separate tag left exactly one row per retried write, including 20 overlapping same-id pairs. Details: [references](references/2026-11-06-show-me-your-work-log-and-page.md).
- **Not yet evaluated:** agents following the guidance on real work, and the owner reading the page.
- **Refresh:** installed caches not refreshed; release not in scope.
