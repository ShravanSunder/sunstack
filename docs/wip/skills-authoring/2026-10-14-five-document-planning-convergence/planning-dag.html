Open behavior question: do repeated reads become useful understanding?

A role charter, a phase and global instructions can each direct a read of the same practice. That overlap may preserve the boundary—or consume context while the agent still merely forwards a result.

This map establishes where the instructions sit. It does not establish a redundant-read cost, a missing-load failure, or a benefit from deduplication. Those require a separately admitted run with the actual loaded source and actions. No “load once forever” rule or automatic deduplication fix is recommended here.
