## Proof plan

Use fresh Sol authors with no inherited authoring history, following the owner's requested model. For a claimed improvement, run the prior and changed skill revisions on the same realistic requests and sources. A passing control means no added value was shown for that case, not a manufactured failure. The current heavily coached Sol copies do not count as fresh application proof.

Freeze requests and checks before launch, keep checks outside the author's working directory and write grant, and retain the complete author tool record and actual outputs. The author sees normal document requests, the intended skill revision and its ordinary dependencies, not the design set, scorecard or corrective brief. Read the loaded SKILL and component-guide paths from the host record rather than the author's report. If that collection route cannot be preflighted, do not launch a counting run.

Run A requests an HTML work account from a staged-import record with material agent decisions, an unresolved assumption, a settled item, a later withdrawal, a meaningful stage denominator, ordered evidence and an untested real provider. Include a source decision with both rationale and material cost; an output that drops the supplied cost fails U1/O1 even when it includes the rationale. The user request asks for a clear progress account rather than enumerating the hidden checks or naming components. Verify U1–U4/O1–O8 against the complete supplied facts, actual selected forms and guide application.

Run B requests a smaller account from another domain with a real agent decision, an incomplete assumption inventory, unrelated status observations and no known total. Check transfer and withholding: the account exposes the actual choice and coverage gap, does not reopen a settled item, and uses prose or a small table rather than invented progress, a forced comparison or an evidence-free sequence.

For R1, inspect its output and evidence reconciliation with unchanged HTML teaching; for R2, inspect fresh combined outputs after R1 and R2 and attribute any difference to the combined revision unless an isolated comparison establishes more. Begin with one control and one candidate per request; repeat fresh runs if variance or a broader reliability claim warrants it. Even consistent results cover the named examples, not all future authors.
