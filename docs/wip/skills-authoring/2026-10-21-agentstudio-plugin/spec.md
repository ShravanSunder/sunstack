## Main path and reference ownership

SKILL.md begins with the scope model, then a short ordered spine:
1. Resolve the helper: supplied AGENTSTUDIO_CLI when available, otherwise the production helper's absolute path; check executable and local help. Bare agentstudio can launch the GUI. Completion: real helper and intended local/app scope are identified, or report unavailable.
2. Establish target/authority. Keep caller identity/environment; self is not focused pane. Background reporting is refused; do not bypass markers. Mutations require existing task authority, and forbidden methods remain forbidden. Completion: intended target/effect fits that authority or report the gap.
3. Load the matching branch reference(s), perform only the requested work or return advice when execution was not requested, then inspect the actual receipt. Completion: selected command/inputs and its observed outcome or unexecuted status are explicit.
4. Route errors through the relevant recovery reference; preserve meaningful IDs, effects and uncertainty. Completion: known resulting state or exact unresolved condition and safe next action; no delivery/permission/completion claim from exit code alone.

The body keeps these invariants near the route: self vs focus; no borrowed credentials/session identity/background bypass; line message vs hook status/ask; no automatic destructive fallbacks; no replay after uncertain delivery or final ordered stale payload. An unavailable reporting path does not cancel otherwise authorized work; chat is the fallback. Detail moves out rather than being duplicated.

Planned ordinary calls (their predicates and returns remain in SKILL.md):
- IF the requested work creates, opens, lists, removes or prunes Git worktrees, load `references/worktrees.md` and return the selected branch/start/content mode, folder, fetch effects and outcome or unmet prerequisite.
- IF the requested work updates an Agent Line/title or sends, reads or withdraws pane notices/asks, load `references/pane-communication.md` and return the actual message/answer state and any usable decision.
- IF the requested work reads the caller pane, drawers or status-engine session context, load `references/pane-context.md` and return the relevant state, returned paging cursors and remaining truncation.
- IF the requested work discovers or executes an App command or uses raw IPC/discovery/event methods, load `references/commands-and-ipc.md` and return the selected live contract, allowed target and actual receipt boundary.
- IF the requested work inspects or controls a terminal/pane or adds a drawer child, load `references/panes-and-terminals.md` and return the resolved own-pane target and observed runtime/input/wait result.
- IF a worktree result fails or has a refusal, skip, partial effect or retained branch that must be resolved, load `references/worktree-recovery.md` and return its exact reason/effects and safe supported next command or owner action.
- IF an app/IPC call is refused, queued, uncertain or otherwise cannot supply its required result, load `references/recovery.md` and return the exact outcome, any known effects and a safe next action or explicit no-CLI-repair gap.

Each opened reference owns its selected local detail, concrete examples, what to inspect/good-vs-bad interpretation, and local completion/stop. It does not repeat its entry predicate or own parent routing. There are no helper-dispatch procedures or shared output schemas.

## Known CLI gaps and non-goals

Supported spelling and source limits are part of teaching, not permission to add product behavior:
- no worktree fork verb; new -c --from provides the source-copy behavior;
- help --help fails; package help is unsupported and provider installation help is unsafe/excluded under explicit Lead disposition;
- no terminal output/capture method listed; terminal.snapshot is runtime metadata;
- no local worktree closePanes/removeWithOpenPanes flags or idle-consumer guarantee; no preserve-staging copy flag;
- agent-notYetAllowed/refusedForAgent boundaries cannot be fixed by raw IPC/command.execute;
- no generic operation.query/resume for accepted/partial/uncertain command receipts;
- ordinary app IPC deadline is5s; raw terminal.wait/subscriptions do not extend it to long requested observations; use documented short bounded forms or report the limit;
