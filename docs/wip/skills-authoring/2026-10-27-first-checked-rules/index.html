First checked rules

Eight of the root's sentences get a rule each: the six judged standards you chose, plus two description checks. They sit in two rule sets, because the engine won't evaluate a set holding a judged rule without a model. The real engine assembles all eight, and runs the two description checks on every skill's SKILL.md. The six judged ones are assembled and printed but not judged by a model yet; that waits for their evals. One command runs them (pnpm --dir tests/skills rules), and two skills switch on their rule step: skill-review runs the rules before its reviewers start, and skill-creation runs them on what it just wrote. Every rule warns; nothing blocks. This is the first real change through milestone 1's new skills, so it also tests them.
