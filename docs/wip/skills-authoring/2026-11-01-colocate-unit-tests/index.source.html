A repository's AGENTS.md says whose standards apply, in one ## Standards line: yours, or the repository's own. With no line, the agent asks you through Sun. It never infers and never mixes (your option A).

The scaffold writes that section into every repository it creates. Under your standards, it links the skills; under the repository's own, it points to the repository's standards file and copies nothing of yours. A retrofit only adds a missing section, and never replaces a file or link, even with --overwrite. The scaffold stops copying the TypeScript and Python rule files. It keeps the Swift and monorepo files as additions only when the instruction file's Standards line names your standards, with their commands deferring to the repository's own.
