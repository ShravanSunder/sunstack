Colocate unit tests

This change puts your test layout into domain-typescript and domain-rust. A unit test sits beside its module. In TypeScript that is report.test.ts. In Rust it is report_test.rs, declared with #[cfg(test)] #[path = "report_test.rs"] mod tests;, your fixed form. The package's tests/ folder holds only integration tests, end-to-end tests and their helpers, in tests/integration/, tests/e2e/ and tests/support/. Both forms hold whatever the repository does elsewhere. Any change to a module, its code or its tests, moves that module's old-form unit tests beside it in the same change. The agent asks you only when the repository's own instructions or checks require a different layout. domain-python already agrees, and no other skill restates where tests go.
