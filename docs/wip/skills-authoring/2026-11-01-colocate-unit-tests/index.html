Shared code standards: the #189 rework

Your standards are written once, in a new hidden skill, domain-code-standards. domain-typescript, domain-rust and domain-python each load it first and keep only their own language's forms.

A repository's AGENTS.md says whose standards apply, in one ## Standards line: yours, or the repository's own. With no line, the agent asks you through Sun. It never infers and never mixes (your option A).

The scaffold writes that section into every repository it creates. Under your standards, it links the skills; under the repository's own, it points to the repository's standards file and copies nothing of yours. A retrofit only adds a missing section, and never replaces a file or link, even with --overwrite. The scaffold writes no rules files at all: their Swift standards become a new hidden domain-swift, and their monorepo standards join the base.
