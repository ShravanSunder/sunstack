Project 1, milestone 1: the root and the lifecycle

Every standard a skill's text must meet moves into one hidden skill, domain-skill-crafting, as one sentence each, so a rule can attach to it in milestone 2. skill-design is new: it produces each change's design set, four parts and a page, with generalization as its own step. skill-creation only writes the files. skill-orchestrator runs the phases, and skill-audit sends flagged skills to skill-review. The change is made in eight runs, one skill each, and the whole move is reviewed as one state, so no standard ever sits in two homes and no link breaks. This is draft 2, by the Lead, revised after the first review; nothing is built yet.
