Project 1, milestone 1: the root and the lifecycle

Every standard a skill's text must meet moves into one hidden skill, domain-skill-crafting, as one sentence each, so a rule can attach to it in milestone 2. skill-design is new: it produces each change's design set, four parts and a page, with generalization as its own step. skill-creation only writes the files. skill-orchestrator runs the phases, and skill-audit sends flagged skills to skill-review. The change is made in thirteen small runs, one skill each, in four groups. Each group moves something together with everything that uses it and is reviewed before the next group starts, so no link ever breaks and no standard is ever in two places. This is draft 4, by the Lead, revised after three review rounds; nothing is built yet.
