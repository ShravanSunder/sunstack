## Obligations

1. The product guide selects the supported call-stack reader and ordinary document/navigation forms; it carries no active requirements/stage/related-browser recipe or retired-element example.
2. Active generic/v2 authoring instructions and current maintainer docs retain their complete positive HTML composition, source-mode and conditional-call-stack meaning after obsolete viewer-specific wording is removed. Frozen v1 and historical records keep their own meaning.
3. Selected call stacks retain their documented prepared input, validation, interaction and source relationship semantics; ordinary explanations carry their facts in visible HTML.
4. Existing call-to-need links reach the prepared record's page and bodyRef; frame.source remains an exact caption, with no new source-link feature.
5. Verification selects the retained call-stack, Comments, inspection, keyboard and source-validation paths, with actual evidence rather than retired-feature expectations.
6. Runtime registration, vocabulary, generated metadata, packaged guide and current examples agree at the declared source build; historical artifacts and negative retirement tests remain classified as history or proof rather than active guidance.
7. Source/static checks, one fresh author observation, review, publication and installed-cache refresh remain separate claims.

## Teaching standards and transfer

The existing house rule “Guidance says what to do and what good looks like” remains owned by skill-crafting/steering; this change adds no generic ban. The product's supported API remains owned by its vocabulary and matching guide. A reference is loaded only for the supported component the author selected.

Transfer case A: a Rust service's design set uses HTML sections, diagrams and shared navigation without selecting a call stack; no prepared reader records are imposed. Pass.

Transfer case B: a TypeScript investigation selects a prepared call stack; its actual need/frame/stack data is prepared and its original source passage is reachable. Removing an unrelated browser must not erase that retained input or fabricate a runtime capture. Pass.

These cases exercise the existing judgments on different document tasks. They create no new cross-repository standard, mandatory diagram quota, default wrapper or output schema.
