# Obligations

- W1: Read the declared source through its cutoff, reconcile newer decisions/closure and identify meaningful episodes; original logs remain authoritative and unchanged.
- W2: Compose the main page around explanatory subjects and supported causal/ordered steps, not one displayed item per stored row or existing Story cache.
- W3: Ordered accounts use a supported Trace whose steps state what happened, why it changed the understanding/work, and the supported result/remaining limit; relevant evidence belongs with that step.
- W4: Preserve complete source access in a clearly labelled companion/archive; coverage is accounted internally, and uncovered/conflicting evidence that could change a conclusion is visible without dumping every row into the primary page.
- W5: Display technical excerpts as code/diff/fenced blocks with declared language when known, inline identifiers as code, and ordinary explanations as prose; don't label whole event envelopes as the explanation.
- W6: Raw API envelopes, machine timestamps and internal identifiers stay in optional source detail unless necessary to interpret a claim; retain stable source IDs and original author/time without making them the story title.
- W7: Keep page authorization, logs/storage, historical identities and acceptance/authority/proof distinctions intact.
- H1: Generic HTML selection explicitly recognizes source, commands, configuration and structured data, loading the matching code guide when they are displayed.
- H2: The Demistify bridge bootstraps matching guide/runtime/trust and delivery choices, delegating current syntax/CLI procedures to the guide rather than duplicating them.

Transfer: release investigations and migration incidents both need episode traces with distinct observed/inferred outcomes; a status-only update has no causal sequence to fabricate. A Rust diff, shell command and JSON response all need technical rendering, while ordinary explanatory prose does not. A1000-row audit can retain full source off the primary path without hiding a material unresolved contradiction. Old thread/post logs lack structured authority tags; retain original provenance rather than inventing them. These tests guard both overfit and over-application.
