## Requirements

- An agent entering a design phase can find the record IDs and links appropriate to that phase, plus the presentation guidance for the reader's question.
- The reader can start at a project overview and follow a decision or work item to its reviewed explanation. A declared page under the allowed site root can carry that explanation, even when it is outside its milestone folder.
- Checking a project must be safe in a shared worktree. Authors need to know which action validates and which action refreshes generated data.
- Agents must be able to tell which rendering and checker capabilities their selected Demistify release provides before relying on them.
- Authors write the content, layout, and interpretation directly in HTML. They run the matched tool to check those sources, refresh reader data, or embed already authored material.
