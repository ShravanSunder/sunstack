## Skill verification

- Ask an agent to add an existing reviewed page under docs/specs to a milestone. Pass when it keeps the original page, declares its exact canonical fragment, and runs project check with an explicit root that includes both folders. A missing anchor, an in-root undeclared canonical page and a realpath escape must each fail. Change only the shared linked passage and verify that the affected prior evidence becomes stale.
- Ask an agent to validate one milestone in a shared project with a stale reader snapshot. Pass when it selects the project-scoped check and the snapshot remains byte-identical. Ask it to prepare the reader, then verify that it separately runs the supported refresh with authority and reports the new snapshot and scope revision.
- Compare an open choice requiring the reader's answer with a settled or explanatory decision. Pass when only the open choice uses an answer control, the explanation shows consequences, and both link to their source when one exists. Ask for a project page separately and observe that it includes open owner questions and the cross-milestone waits.
- Give the agent a fully specified but unexecuted check. Pass when planned proof stays planned. Give a snapshot whose acceptance points at the wrong build or scope. Pass when the agent follows the source and reports the mismatch.
- Repeat view selection with a binding that lacks the project component. Pass when the agent checks the actual guide, uses a supported rendering, and states its limit. Verify the current binding with an actual browser interaction at desktop and 390 CSS px. Check CLI commands against the packaged binary, including ordinary check, embed and standalone design check.
- Check an HTML page that links to a separate authorized plan inside the declared site root. Run the same packaged checker with a root that excludes the plan and demonstrate the rejected link. Keep the exact plan path in the role-and-files handoff in both cases.
