A design you can review

In this example, a person can cancel a queued job until a worker claims it. Follow that one promise from the user’s request through the design and its planned proof. The view changes at each step because the reader is asking a different question.

Follow the worked example or review the proposed skill changes.

What does the person experience?

After submitting a job, the person gets a job ID. If the job is still queued, cancelling it ends the job before the worker starts. If the worker already claimed it, the person sees that it is running.

The sequence belongs in Requirements. It shows what the person sees and what changes when they act earlier or later.

Which outcome wins?

A queued job can leave the queue through one of two transitions. Once cancellation wins, the worker has no path from Cancelled to Running.

What the person can do

Stop a queued job. If it is running, see its current state.

What the service must handle

Resolve the race between cancelling and claiming.

What the person can do

Request a stop after the worker starts. Effects already produced can remain.

What the service must handle

Signal the worker and explain what stopping means when a job has already written results.

The Specification uses the state diagram for the queued-only rule. The comparison shows the product tradeoff a reader can inspect. Use Choice with Details when the reader is being asked to make that decision.

Who decides whether the worker can start?

The job store owns the transition out of Queued. The API requests cancellation and the worker requests a claim. Both use the same conditional update, and the worker starts only when the store confirms its claim.

The Program Design uses this view to show where the two paths meet. Give the reviewed passage a stable ID such as ownership. The realization record can point there and name the rule it implements.

What would prove the race is handled?

The Verification Design names the order each case must force and what would settle it. These observations are planned.
