Rules in use · draft 3

What changed in draft 3 and why?

Jev, the model that judges skill standards, runs by default. Each of the twelve checked standards is a decision model over one kind of evidence that ast-grep picks from a skill: a description, a step, a load, a branch, a sentence or a reference section. A gate decides whether the piece is one the standard covers; the verdict judges it; an uncertain piece goes back to the agent running the check. Read the need and its evidence in Requirements.

Draft 3 runs on the engine change the owner confirmed on 29 October and that was then built: sunstack lint --config, one config instead of three RuleSets, and rule tests as labelled real cases in tests/skills. See the shape and the runs and their status.

All seven skill descriptions are rewritten at 165 to 182 characters, keeping their triggering purpose. The standards root stays hidden from implicit invocation. Read the exact descriptions and their trials.
