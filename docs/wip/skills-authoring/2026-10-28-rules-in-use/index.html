Rules in use · draft 2

What changed from draft 1 and why?

Jev, the model that judges skill standards, now runs by default. Each judged standard becomes a decision model: it selects the pieces of a skill it governs, checks whether each belongs, then judges it. Draft 1 made Jev optional and put workarounds in the caller; draft 2 puts that work in the engine. Read the correction and its evidence in Requirements.

The engine comes first: amendment A22 supplies the missing engine capabilities, and its release is the dependency before the skill changes begin. See the shape and the order of work.

All seven proposed skill descriptions are now written out, keeping their triggering purpose in fewer words. The standards root stays hidden from implicit invocation. Read the exact descriptions and their planned trials.

The four parts below are the design's source of truth. Skill verification is the plan for showing the change works; it is not a record of completed proof.
