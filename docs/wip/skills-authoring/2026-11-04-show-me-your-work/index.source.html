Show me your work: skill design

This change makes show-me-your-work keep your picture of a running design or implementation current. Every agent on the work records what happened, each decision with whose authority it rests on, each assumption, each design change and each proof in Router's work trail, as it happens, tied to the part of the design or plan it concerns. You read one live page per piece of work, built from that record, with the design or plan part by part and what happened beside each part. Decisions you have to make come to you on their own pages.

It changes eight skills, one run each: practices-show-me-your-work, then the seven that record work: role-implementer, implement-plan, orchestrator-implementation-goal, practices-collaboration, orchestrator-design, role-advisor and plan-implementation.

- **Assumptions and calls for you to strike if wrong** (decisions table): D6, deciding happens on its own pages, which the live page links to; D7, your main view is the design or plan with entries beside each part; D15, the four extra runs so the record has one home. - **The design review.** The first review returned five findings; this revision answers them, and the same reviewer checks it again. No skill file changes until it accepts. - **Decided by you, later:** the Jev importance check (a later run) and the trigger trial (with the later pressure tests). - **Not proven here:** agent behavior under pressure, and a Sidekick writing entries in a real assignment.

The four parts

  1. Requirements: the change, your success definition in your words, the evidence and the non-goals.
  2. Specification: what the skill must do, one sentence each, the stop list, and the rules with their transfer cases.
  3. Skill design: the four runs, the new trigger and main path, the references and script, the security decision, the decisions table you can strike, and coordination.
  4. Skill verification: each item's proof route, the proof plan, the trigger trial, and what stays unverified.
