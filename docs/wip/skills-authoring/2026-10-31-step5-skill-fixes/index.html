Step 5 skill fixes: design set

This change fixes the 89 real failures that step 5's rules run found in 44 skills. It rewrites descriptions that are too long or that list a skill's contents, adds completions to steps that never say when they're done, turns branch conditions built on the agent's own doubt into conditions it can see, and makes two calls say what they return. It runs as six PRs, one per family, built and reviewed one at a time; the owner reviews and merges each. The 81 steps that wait on the owner's completion-phrasing decision are left alone. Still open: the design review of this set.

Walkthrough

  1. Requirements: what changes, the owner's words, the success definition, the evidence and the scope.
  2. Specification: the seven things that must hold after each run.
  3. Skill design: how each kind of finding is fixed, the six runs, run 1's drafts and the decisions.
  4. Skill verification: how each obligation is checked, and what stays unverified.
