Step 5 skill fixes: design set

This change fixes the 89 real failures that step 5's rules run found in 39 skills. It rewrites descriptions that are too long or that list a skill's contents, adds completions to steps that never say when they're done, turns branch conditions built on the agent's own doubt into conditions it can see, and makes two calls say what they return. Each skill is its own authoring run, 44 runs in all, and the runs are grouped into six PRs, one per family, built and reviewed one at a time. The owner reviews and merges each PR. The 81 steps that wait on the owner's completion-phrasing decision are left alone, and every existing guard on the sensitive text the edits touch stays as it is. This is draft 2, after the design review's four findings. Still open: the reviewer's recheck.

Walkthrough

  1. Requirements: what changes, the owner's words, the success definition, the evidence and the scope.
  2. Specification: the seven things that must hold after each run.
  3. Skill design: how each kind of finding is fixed, the six runs, run 1's drafts and the decisions.
  4. Skill verification: how each obligation is checked, and what stays unverified.
