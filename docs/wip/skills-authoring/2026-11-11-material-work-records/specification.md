# Obligations

- R1: A new record carries a material change to work, understanding, authority, risk, evidence or next action; this criterion also governs audit omissions and completion.
- R2: Related required checks may share one material proof record with each target/result/receipt and limits; every required check still runs and failures remain visible.
- R3: A retained inspected capture/cutoff/open state may be reused; before calling its conclusions current, read every row in the requested scope after that cutoff through the newly declared cutoff, then judge relevance; missing context/provenance or a wider requested scope requires reconstruction.
- R4: Rendering consumes a declared source snapshot without writing summaries, missed rows, audit/proof or checkpoint records back into that source.
- R5: Known helper access failure is recorded once per affected stretch with runner attribution; silence adds no still-open replacement.
- R6: Stop classification preserves all six authority/treatment predicates, without mandatory matching to old incidents.
- R7: Ordinary tracking creates no page; the page skill keeps explicit-only invocation and its existing presentation procedure.

Transfer: R1/R2 cover a test suite and a deployment rehearsal; repeated identical successful probes add no knowledge. R3 covers a single-writer local record and a growing remote feed; an unread late correction blocks reuse of an older conclusion. R4/R7 cover an incident page and a review history; a historical page request is not current authorization. R5 covers multiple handbacks from one unreachable worker and a real omitted required check; the latter remains Missed. R6 covers an authorized reversible choice unrelated to old examples and an uncovered storage choice; the uncovered choice still holds. All pairs preserve useful evidence without new schemas.
