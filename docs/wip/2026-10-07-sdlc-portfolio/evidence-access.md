# Local evidence access

Historical session records, evaluator observations, reviewer outputs and transport details remain local or private. Their contents and machine paths are excluded from this bundle. Public repository sources use exact-revision links.

Each stable key below identifies supporting evidence, not publicly reproducible proof. The audit owner retains the exact key-to-source mapping in an ignored local index. A reviewer with authorized local access can use that index to inspect the record; a public reader cannot independently reproduce the historical claims from these keys alone. The report preserves the evidence cutoff and sampling limits beside the claims.
