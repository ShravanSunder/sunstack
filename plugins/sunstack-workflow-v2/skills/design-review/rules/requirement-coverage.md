# Requirement coverage standards

These are id-level proxies for the chain in [reviewing-four-document-design.md](../references/reviewing-four-document-design.md#requirement-to-observation), where every link from a requirement to its observation uses the same ids. An id that appears is not proof the need is addressed, and an id that is missing is not proof it isn't; each result is worth checking.

- Each requirement id defined on the Requirements page appears on the Specification page, where an obligation links it. <!-- C001 -->
- Each requirement id defined on the Requirements page appears on the Program Design page, in the trace rows of the obligations it reaches. <!-- C002 -->
- Each requirement id defined on the Requirements page appears on the Verification Design page, on the row that plans its observation. <!-- C003 -->
- A design set's Requirements page has its Specification page beside it, or the Specification is named once as not yet written. <!-- C004 -->
- A design set's Requirements page has its Program Design page beside it, or the Program Design is named once as not yet written. <!-- C005 -->
- A design set's Requirements page has its Verification Design page beside it, or the Verification Design is named once as not yet written. <!-- C006 -->
