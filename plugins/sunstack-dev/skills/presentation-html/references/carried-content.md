# Carry existing content onto a page

This reference owns how content the request carries onto the page (a conversion, migration or re-render) keeps its meaning. Expected inputs: the source content and the request. Return: each carried form and initial state, and each change with the note beside it.

When the request carries existing rich content onto the page (a conversion, migration or re-render), carry its meaning, not only its words: its form, order and relationships, its status and icon labels and other supported attributes, and each disclosure's initial open or closed state. When you compose an explanation from a source's facts instead, its lists and tables are not a required presentation; `SKILL.md` step 2 chooses their views. Change a carried form or state only when the request or the reader's task calls for it, never because the chooser or a step 4 default in `SKILL.md` prefers another; the change keeps the meaning, and a brief note beside the content names it. A meaning the matching guide cannot represent stays as text beside its view, with the same note. A status, category or other value the source leaves unspecified stays unspecified. Keep whitespace that carries structure or literal content; other whitespace and harmless markup may change without a note.

Complete when each carried meaning, form and initial state is kept, or its change has a note beside it.
