# Mechanical picture-before-control observation

This held companion has no model questions, filters or selections. It reports one source fact: a configured picture element precedes a native choice in its innermost heading section, on a structurally proven direct-heading layout. It does not certify relevance, a current model, tradeoffs, rendering, or that a full design brief is owed.

A picture can be direct or nested in a preceding sibling. A heading within an intervening wrapper makes that layout unsupported, so the result is uncertain rather than an inferred absence. Template examples and configured outline-skip components are excluded from heading boundaries. The broader source-range-relative helper is still missing.

Use `picture-before-control.config.json` explicitly with released CLI 0.16.0 and `--root <document-root>`. Its AST project reads the existing native-choice selector without changing O001's files and keeps its own two observation predicates isolated. No active rulebook invokes this config.

Check/list/evidence inspection precedes independent review. The six real-case campaign waits for that review; no model credential or provider request is needed. The candidate remains held even if the literal source checks match all six cases.
