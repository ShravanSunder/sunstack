This held companion has no model questions, filters or selections. It does not certify relevance, a current model, tradeoffs, rendering, or that a full design brief is owed.

A picture can be direct or nested in a preceding sibling. Supported pictures include native configured elements and a standalone triple-backtick Mermaid fence inside a single `ex-markdown` / `script type="text/markdown"` island. This recognizes a source form, not valid or rendered Mermaid. Template examples do not count.

A heading within an intervening wrapper makes that layout unsupported, so the result is uncertain rather than an inferred absence. Markdown islands are supported only as the standalone Mermaid form or plain content without possible heading, image, raw HTML or fence syntax. Other islands stop boundary proof.
